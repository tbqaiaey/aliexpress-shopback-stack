## Where AliExpress promo codes actually come from

Almost every code you'll find falls into one of four buckets, and they behave differently.

**Platform campaign codes.** The big sales — Choice Day, anniversary events, 11.11 — come with their own code sets. These tend to be tiered by order value rather than a flat percentage. A deal site running a Choice Day promotion, for example, published a ladder of codes tied to spend thresholds: spend $15 to save $2, stepping up through $30 save $4, $65 save $9, $109 save $15, $169 save $23, $259 save $35, $379 save $55, and $499 save $70, with the window closing on a set date. You pick the code that matches your cart, not the biggest number on the list.

**Store coupons.** Issued by a single seller, scoped to that seller's catalogue, usually with a minimum spend. These are the codes you see most often on deal forums, and they don't travel. A $15-off code circulating for one seller's electric scooter listing won't do anything in a different store's cart.

**Creator and affiliate codes.** Deal blogs and newsletter writers get allocated codes to share. Same logic as store coupons — scoped, time-limited, often tiered.

**New-customer pricing.** This one isn't a code at all. AliExpress shows a lower price automatically to accounts with no order history, and it varies by account. Worth knowing because it usually doesn't stack: the source of that Hip2Save code ladder noted explicitly that their coupons won't apply on top of the new-customer price.

Two practical details that cause most "the code didn't work" complaints. You need to be signed into your AliExpress account with a saved delivery address before the code field will behave, and you generally have to type the code in manually rather than paste it from anywhere. Once a code is applied, you can't swap in a different one — clear your cart and rebuild it if you picked the wrong tier.

## The rule nobody puts on the code list

Here's the part that changes how you shop.

ShopBack's terms state that amounts paid using gift cards, vouchers, promo codes, discount codes or store credit do **not** earn cashback. The real risks sit elsewhere: the exclusion clause above, and the fact that a code changes your order total, which can move you across a spend threshold or affect eligibility for new-customer pricing. ## Caps, timelines and the 90-day confirm

Four mechanics trip people up more than the rate itself.

**Rates are calculated per item.** ShopBack's terms are explicit that the cashback rate depends on the product purchased, so a single AliExpress order with six items can produce six different rates. A single "you earned 12%" figure for the whole order is normal only when every line sits in the same category.

**There's a cap, and it's per transaction or per item depending on market.** Australia used A$50 per transaction. Korea used ₩30,000 per item. Above the cap, extra spend earns nothing extra.

**Approval takes time.** In the Korean terms, cashback is forecast to complete approval around seven days, with the full window running to roughly 95 days. Cashback usually shows as pending first, then flips to confirmed after the merchant settles. If a store displays zero during review, the amount is adjusted later.

**You have to confirm receipt within 90 days.** Cashback can be rejected if the order isn't marked as received inside that window, and some orders auto-confirm once tracking shows delivery. Setting a reminder for anything large is not paranoia.

One more warning from the Australian deal thread worth repeating: only one AliExpress account can be attributed to your ShopBack account. Creating a second AliExpress account to chase the new-customer rate won't work — the second one earns the existing-customer rate — and AliExpress may suspend alt accounts for it.

The usual suspects: visiting AliExpress directly instead of clicking through ShopBack, switching tabs mid-checkout, ad blockers, a cancelled or returned order, or a product that isn't affiliated with the cashback program.
